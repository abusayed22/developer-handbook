# 🛠️ Express.js + Prisma Clean Backend Architecture

A modular, scalable folder structure for production-ready Node.js APIs.

## 📂 Directory Layout
```text
src/
├── config/         # Environment variables & DB client instance
├── controllers/    # Request handlers & response formatting
├── middlewares/    # Authentication, validation, and error middlewares
├── routes/         # API Route definitions
├── services/       # Business logic & Database interactions
├── utils/          # Helper functions & custom response handlers
└── app.js          # Express app entry point
